# Trabajo Práctico Integrador (TPI) - Programación 1
**Tecnicatura Universitaria en Programación - UTN**

## Descripción
Aplicación en Python 3 para gestionar datos de países desde un archivo CSV, aplicando listas, diccionarios, funciones, condicionales, bucles, ordenamientos, filtros, estadísticas y validaciones de entrada.

## Archivos del proyecto
* `main.py`: código principal del menú y las funciones.
* `paises.csv`: archivo CSV con los datos de países.
* `README.md`: documentación del repositorio.

## Cómo ejecutarlo
1. Tené instalado **Python 3**.
2. Poné `main.py` y `paises.csv` en la misma carpeta.
3. Abrí una consola en esa carpeta y ejecutá:
   ```bash
   python main.py ```
   ## Funcionalidades del menú
1. Agregar un país (sin campos vacíos ni duplicados).
2. Actualizar población y superficie de un país.
3. Buscar un país por nombre (coincidencia parcial o exacta).
4. Filtrar países por continente, rango de población o rango de superficie.
5. Ordenar países por nombre, población o superficie (ascendente o descendente).
6. Mostrar estadísticas (mayor y menor población, promedios y cantidad por continente).
7. Salir.
